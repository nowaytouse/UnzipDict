# UnzipDict

macOS 原生解压工具，支持密码字典自动尝试。灵感来自 Windows 工具「解TM的压」。

## 功能

- **4层密码队列**: 字符匹配 → 缓存 → 单次 → 永久
- **智能排序**: 成功次数多的密码优先
- **隐写包检测**: 检测图片/视频中的隐藏压缩包
- **分卷压缩包**: 自动识别并跳过非首包
- **递归解压**: 自动解压嵌套压缩包
- **乱码修复**: 自动修复日文/中文乱码文件名
- **动态解压**: 搜索完一个目录立即开始解压
- **悬浮密码框**: 随时添加密码
- **原生液态玻璃UI**: macOS 26 Tahoe 风格

## 要求

- macOS 26.0+
- 7-Zip: `brew install p7zip`

## 编译

```bash
swift build -c release
```

## 使用

1. 拖放压缩文件或目录到窗口
2. 点击「开始解压」
3. 通过菜单栏图标显示悬浮密码框

## 密码格式兼容

支持导入原作者格式的密码文件：
```
密码1    123
密码2    45
```
（密码 + Tab + 成功次数）
